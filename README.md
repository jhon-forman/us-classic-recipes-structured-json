# 🍔 US Classic Recipes Structured Dataset (JSON & Markdown)

A clean, open-source collection of popular American recipe datasets structured into machine-readable JSON and Markdown formats. Built for developers, local LLM testing, meal planning apps, and culinary data scraping projects.

## 📂 What's Inside?
- **JSON Format:** Ingredients, nutritional estimates, prep/cook times, and step-by-step instructions properly nested.
- **Markdown Format:** Human-readable recipe cards optimized for static site generators and LLM prompt testing.
- **US Standard Measurements:** Cups, ounces, Fahrenheit, and standard US cooking terms.
